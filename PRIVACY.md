# Privacy Policy

Last updated: August 23, 2026

Web Please processes limited web-browsing information locally on your device solely to provide its advertised feature. It uses Chrome's packaged declarative request rules to recognize supported Google Search URLs and add Google's Web-results setting (`udm=14`). When you use the toolbar switch, it also reads and updates the URL of the active Google Search tab so the change takes effect immediately. A Google Search URL may contain the search terms you entered.

This information never leaves your device. Web Please does not log, retain, transmit, sell, share or use it for advertising, profiling, analytics, creditworthiness or lending. The extension does not read page contents, create accounts, use cookies or contact a developer-controlled server.

All extension logic and request rules are included in the installed package. Web Please does not load or execute remotely hosted code.

If you choose the optional Ko-fi support link, Chrome opens Ko-fi as a separate third-party website. That visit is governed by Ko-fi's own privacy practices; Web Please does not receive information about it.

Web Please uses information received from Chrome APIs only to provide its single purpose and in accordance with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Web Please is not affiliated with or endorsed by Google.
