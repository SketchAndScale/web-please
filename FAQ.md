# Frequently asked questions

## Does Web Please disable Google’s AI system?

No. It asks Google to show its Web-results view for ordinary searches. Google’s AI systems are not modified.

## Why are some cards missing?

Web mode is text-focused. Google may omit knowledge panels, currency, sports, weather, featured answers and other rich-result modules.

## Does it affect Images or News?

No. Explicit search modes remain available. The extension only changes ordinary Search result requests.

## Does it read my searches?

Chrome processes supported Google Search URLs locally to apply Web mode. Web Please never logs, retains, transmits, sells or shares that information.

## What does `-ai` do?

It is a normal Google exclusion term. It can remove results containing the word “AI,” but it is not a reliable AI Overview switch.
